# Images Folder

This folder contains images used in the LTA Partners website prototype.

## Recommended Structure:

```
images/
├── logo-lta.png          # Main logo (PNG)
├── logo-lta.svg          # Main logo (SVG - preferred)
├── logo-lta-white.png    # White version for dark backgrounds
├── hero/
│   └── office.jpg        # Hero background images
├── team/
│   └── [employee photos] # Team member photos
└── icons/
    └── [service icons]   # Custom icons if needed
```

## Image Guidelines:

### Logos:
- **Format:** SVG (preferred) or PNG with transparency
- **Size:** 150-300px width
- **Background:** Transparent

### Hero Images:
- **Format:** JPG or WebP
- **Size:** 1920x1080px minimum
- **Optimization:** Compress to < 500KB

### Team Photos:
- **Format:** JPG or WebP
- **Size:** 400x400px (square)
- **Style:** Professional headshots
